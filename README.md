# SimpleLocalChatbot

自分のパソコン（ローカル環境）で動くAIモデル（Ollama）と、日本語で会話できるデスクトップアプリです。  
通常のチャットや画像を見せる質問は**すべて自分のパソコン内で処理されるため、無料で何度でも**利用できます。

### 📥 アプリのダウンロード方法
**[👉 ここをクリックしてアプリ一式（SimpleLocalChatbot.zip）をダウンロード](https://github.com/shred0901-DEV/SimpleLocalChatbot_pywebview/raw/refs/heads/main/SimpleLocalChatbot.zip)**

※ダウンロードした `SimpleLocalChatbot.zip` は、**必ず「右クリック → すべて展開」で解凍してから**使ってください（ZIPを開いたまま実行すると動きません）。

## 1. はじめに準備するもの（初回のみ）

このアプリを動かすには、最初に以下の **3つの準備** を行います。

### ① Python 3.11 以上をインストールする
まだパソコンに Python が入っていない場合は、[Python公式サイト](https://www.python.org/downloads/) から **Python 3.11 以上** をダウンロードしてインストールしてください。
- インストール画面の最初にある **「Add python.exe to PATH」にチェック** を入れてから「Install Now」を押してください。

### ② Ollama（AIを動かすソフト）をインストールする
AIモデルをパソコン上で動かすための無料ソフト「Ollama」をインストールします。
1. [Ollama for Windows ダウンロードページ](https://ollama.com/download/windows) を開き、インストーラー（`OllamaSetup.exe`）をダウンロードします。
2. ダウンロードしたファイルを実行してインストールします（インストール後、画面右下のタスクトレイにアルパカのアイコンが表示されれば起動しています）。

### ③ AIモデル（Gemma）をダウンロードする
VRAM 8GB 程度のGPUを搭載したパソコンで快適に動き、日本語の会話や画像の読み取りにも対応している **Gemma 4（`gemma4:e4b`）** をダウンロードします。

1. キーボードの **Windowsキー** を押し、`PowerShell` と入力して **「Windows PowerShell」** を開きます。
2. 次のコマンドを入力（または貼り付け）して **Enter** キーを押します。
   ```powershell
   ollama pull gemma4:e4b
   ```
3. ダウンロードが始まります（数GBあるため数分かかります）。`success` と表示されたら完了です。PowerShell は閉じて構いません。
   - ※ より軽量なモデルを使いたい場合は `ollama pull gemma3:4b`、VRAMに余裕（12GB以上）がある場合は `ollama pull gemma4:12b` なども追加できます。
   - ※ 新しいモデルが読み込めない場合は、Ollamaを最新版に更新してください。

## 2. アプリのセットアップと起動方法

### 初回セットアップ（最初の1回だけ）
フォルダの中にある **`setup.bat`** をダブルクリックして実行します。
- アプリに必要な部品（`pywebview`、`Pillow`、`requests`）が自動で専用フォルダ（`.venv`）にインストールされます。
- `=== Setup completed successfully. ===` と表示されたら、何かキーを押して画面を閉じます。

### アプリの起動（2回目以降はこちらだけ）
フォルダの中にある **`run.bat`** をダブルクリックすると、チャット画面が起動します。

---

## 3. チャットの使い方

画面は左側に **「コントロールパネル」**、右側に **「チャット」** が並んでいます。

1. **モデルの確認**: アプリを起動すると、自動的に Ollama（初期接続先 `http://127.0.0.1:11434`）へ接続し、ダウンロード済みのモデル（`gemma4:e4b` など）が入力欄の下の「モデル」欄に選ばれます。
   - ※ アプリを起動したあとに Ollama を立ち上げた場合や、新しいモデルを追加した場合は、**「接続確認・モデル再読込」** ボタンを押してください。
2. **メッセージを送る**: 右下の入力欄に日本語で質問やメッセージを入力し、**「送信」ボタン** または **Enterキー** を押します。
   - 文章の途中で改行したいときは **Shift ＋ Enter** を押します。
   - AIの回答が少しずつ表示されます。途中で止めたいときは **「中止」** を押してください。
3. **会話を切り替える・新しく始める**:
   - 左側の **「新しい会話」** を押すと、これまでの会話を残したまま新しい話題を始められます。
   - **「会話の履歴」** の一覧をクリックすると、過去の会話をいつでも続きから再開できます。

### 画像を添付してAIに質問する
`gemma4:e4b` や `gemma4:12b` などの画像対応モデルを選んでいるときは、画像を見せて質問できます。
- **添付の方法**:
  - 「画像を添付」ボタンから画像ファイル（PNG / JPEG / WebP / BMP / GIF）を選ぶ
  - スクリーンショット等をコピーした状態で、入力欄に貼り付ける（Ctrl ＋ V）
  - 画像ファイルを入力欄やチャット欄へドラッグ＆ドロップする
- 1回のメッセージにつき **最大3枚** まで添付できます（自動で長辺1600px以下に縮小され、位置情報などのEXIFメタデータは除去されます）。
- 間違えて添付した場合は、サムネイル右上の **「×」** ボタンで外せます。文字を入力せずに画像だけを送ると、AIが画像の内容を日本語で説明します。

## 4. Web検索機能とクレジット表示について（有料オプション）

入力欄の下にある **「Web検索を使う」** にチェックを入れると、Ollamaの公式Web検索APIを使ってインターネット上の最新情報を調べてから回答させることができます。

> **【重要】Web検索機能の利用には課金（最低5ドル分のクレジット購入）が必要です**  
> OllamaのWeb検索機能は有料APIとなっており、**最低でも5ドル（\$5 USD）分のOllamaクレジットを購入（チャージ）しないと利用できません（無料・無課金の状態ではエラーになりWeb検索は使えません）。**  
> ※「Web検索を使う」をOFFにした通常のチャットや画像質問は、課金なしで完全無料で使えます。

### Web検索を使うための設定手順（課金済みの方のみ）

1. [Ollamaの課金・クレジット設定ページ](https://ollama.com/settings/billing) でクレジット（最低5ドル〜）を購入します。
2. [OllamaのAPIキー設定ページ](https://ollama.com/settings/keys) で APIキーを作成し、コピーします。
3. Windowsの「ユーザー環境変数」に APIキーを登録します。
   1. キーボードの **Windowsキー** を押し、`環境変数` と検索して **「環境変数を編集」** を開きます。
   2. 上側の「（ユーザー名）のユーザー環境変数」にある **「新規(N)...」** ボタンを押します。
   3. **変数名** に `OLLAMA_API_KEY`、**変数値** にコピーしたAPIキーを入力して「OK」を押します。
4. アプリを起動し直すと、左側の「Ollamaクレジット（USD）」欄に残高と消費量が表示され、「Web検索を使う」をONにして質問できるようになります。

## 5. データの保存場所と整理について

このアプリの設定や会話データは、パソコンのシステム領域を汚さず、**すべてこのアプリのフォルダ内（`data/` フォルダ）** に自動で保存されます。

- `data/chat.json` : Ollama接続先の設定、会話の履歴（1会話につき最大100往復）、入力途中の下書き
- `data/chat_images/` : 会話に添付した画像のコピー
- `data/logs/` : 動作ログ

会話をすべて初期状態に戻したい場合は、アプリを終了した状態で `data` フォルダを削除してください。
